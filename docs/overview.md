# 记账桌面端应用 - 需求文档与架构文档

## 第一部分：需求文档

### 1. 项目概述
本项目旨在开发一款跨平台的桌面记账应用，采用 Electron 构建用户界面，Java 提供后端业务逻辑与数据存储服务。应用支持离线使用，数据存储在本地，具备账户管理、收支记录、分类统计、预算管理等功能，帮助个人或小型团队高效管理财务。

### 2. 目标用户
- 个人用户：日常收支记录、消费分析、预算控制。
- 家庭用户：多人共同记账，共享账户与分类。
- 小型工作室/自由职业者：项目收支跟踪、简易财务报表。

### 3. 功能需求

#### 3.1 账户管理
- 支持创建、编辑、删除账户（如现金、银行卡、支付宝、微信等）。
- 账户余额自动计算（初始余额 + 收入 - 支出）。
- 账户间转账功能，记录转账手续费（可选）。
- 账户列表展示，支持排序与隐藏。

#### 3.2 收支记录
- 添加收入/支出记录：金额、日期、账户、分类、备注、标签。
- 支持多币种（可选，默认人民币）。
- 记录编辑、删除、复制。
- 快速记账模板（常用收支一键录入）。
- 搜索与筛选：按日期范围、账户、分类、金额区间、关键词。

#### 3.3 分类管理
- 内置默认分类（餐饮、交通、购物、娱乐、工资、奖金等）。
- 用户可自定义分类，支持多级分类（父子分类）。
- 分类图标与颜色设置。
- 分类排序与归档。

#### 3.4 统计报表
- 收支趋势图（折线图、柱状图）：按日、周、月、年。
- 分类占比饼图/环形图。
- 账户余额变化图。
- 自定义时间范围对比分析。
- 报表导出（CSV、PDF）。

#### 3.5 预算管理
- 设置月度总预算、分类预算。
- 预算使用进度条与超支提醒。
- 预算执行情况历史对比。

#### 3.6 数据管理
- 本地数据库存储（SQLite）。
- 数据备份与恢复（手动/自动备份到本地文件）。
- 数据导入（CSV、Excel）与导出。
- 数据加密（可选，AES加密本地数据库）。

#### 3.7 设置与个性化
- 主题切换（浅色/深色/自定义颜色）。
- 货币符号与小数位数设置。
- 启动时是否自动打开上次窗口位置。
- 快捷键自定义。

#### 3.8 其他
- 多语言支持（中文、英文等）。
- 系统托盘快捷记账。
- 全局快捷键调出快速记账窗口。

### 4. 非功能需求

#### 4.1 性能
- 启动时间 ≤ 3 秒（冷启动）。
- 列表滚动流畅，万条记录操作响应 ≤ 500ms。
- 报表生成 ≤ 2 秒。

#### 4.2 兼容性
- 支持 Windows 10+、macOS 11+、主流 Linux 发行版（Ubuntu 20.04+）。
- 屏幕分辨率适配 1024x768 以上。

#### 4.3 安全
- 本地数据默认明文存储，提供可选的加密选项（AES-256）。
- 用户敏感操作（删除账户、清空数据）需二次确认。
- 防止 SQL 注入（使用参数化查询）。

#### 4.4 可维护性
- 前后端分离，接口清晰，便于单元测试与替换。
- 代码遵循 ESLint/Checkstyle 等规范。

### 5. 用户界面要求
- 简洁直观，符合主流桌面应用操作习惯。
- 主界面分为：侧边导航栏（账户、流水、报表、预算、设置）与内容区。
- 支持拖拽排序、批量操作（多选删除、修改分类）。
- 空状态友好提示。

### 6. 里程碑与交付物
- M1：基础架构搭建（Electron + Java 通信）、数据库设计、账户与流水 CRUD。
- M2：分类管理、统计报表（基础图表）、预算设置。
- M3：数据备份恢复、导入导出、多语言、主题。
- M4：性能优化、安全加固、打包发布（安装包/绿色版）。

## 第二部分：架构文档

### 1. 技术选型

| 层次   | 技术                               | 说明                                            |
| ------ | ---------------------------------- | ----------------------------------------------- |
| UI 层  | Electron + Vue + Element UI        | 桌面壳，渲染界面，调用 Java 服务                |
| 通信层 | 本地 HTTP（REST API)               | Electron 主进程启动 Java 子进程，通过 HTTP 通信 |
| 后端层 | Java 17 + Spring Boot (或轻量框架) | 业务逻辑、数据访问、报表计算                    |
| 数据库 | SQLite（通过 JDBC 或 JPA）         | 本地单文件数据库，无需独立安装                  |
| 图表   | ECharts / Chart.js                 | 前端图表渲染                                    |
| 打包   | electron-builder + jpackage        | 生成各平台安装包                                |
